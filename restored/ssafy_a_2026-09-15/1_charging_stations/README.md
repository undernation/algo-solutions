# [SSAFY A형 1번 복원] 충전소 설치

시험일: 2026-09-15 · 아카이브 전용 번호: SWEA/99997

시간 제한: **50개 테스트케이스 합산 약 10초** (응시자 기억). 메모리 제한은 미확인.

> GitLab에 있는 풀이 2개와 입력 5개를 바탕으로 작성한 복원 문제입니다.
> 제목과 설명은 복원 과정에서 붙였으며, 99997은 공식 SWEA 문제 번호가 아닙니다.
> 원본 `output.txt`는 비어 있습니다. 아래 출력은 원본 풀이와 독립 구현을 대조해 계산했습니다.

## 문제

정수 좌표로 나타내는 마을에 N개의 집이 있다. i번째 집의 좌표는 (x_i, y_i)이고, 이 집에서 이용할 수 있는 충전소까지의 최대 거리는 d_i이다.

충전소를 설치할 수 있는 위치는 x좌표와 y좌표가 각각 -15 이상 15 이하인 정수 좌표이다. 집이 있는 위치에는 충전소를 설치할 수 없다. 충전소를 두 개 설치할 때는 서로 다른 위치에 설치해야 한다.

집 (x, y)와 충전소 (a, b) 사이의 거리는 맨해튼 거리 |x-a| + |y-b|이다. 각 집은 설치된 충전소 중 가장 가까운 곳을 이용한다. 모든 집이 충전소를 이용하려면 각 집에서 가장 가까운 충전소까지의 거리가 그 집의 d_i 이하여야 한다. 한 충전소를 이용하는 집의 수에는 제한이 없다.

다음 우선순위에 따라 충전소를 최대 두 개 설치하려고 한다.

1. 충전소 하나로 모든 집의 거리 조건을 만족시킬 수 있다면 반드시 하나만 설치한다.
2. 하나로 불가능할 때만 두 개를 설치한다.
3. 위에서 결정한 설치 개수 안에서, 각 집과 가장 가까운 충전소 사이의 거리 합이 최소가 되도록 한다.

구해야 하는 값은 이때의 최소 거리 합이다. 충전소 두 개로도 모든 집의 거리 조건을 만족시킬 수 없다면 -1을 출력한다.

설치 개수를 줄이는 것이 거리 합을 줄이는 것보다 우선한다. 따라서 두 개를 설치하면 더 짧은 거리 합을 얻을 수 있더라도, 하나로 가능하다면 하나를 설치한 결과를 출력한다.

## 입력

첫째 줄에 테스트케이스 수 T가 주어진다.

각 테스트케이스의 첫째 줄에 집의 수 N이 주어진다. 다음 N개의 줄에는 각 집의 x좌표, y좌표, 허용 거리 d가 공백으로 구분되어 주어진다.

```text
T
N
x_1 y_1 d_1
...
x_N y_N d_N
```

## 출력

각 테스트케이스마다 `#테스트케이스번호 정답` 형식으로 출력한다. 번호는 1부터 시작한다. 정답은 설치 우선순위를 지킨 최소 거리 합이며, 불가능하면 -1이다.

## 예제 설명

- 1번: 집 (-2, 0)과 (1, 3)을 하나의 충전소로 감당할 수 없다. (-1, 0)과 (1, 2)에 각각 설치하면 두 집 모두 거리 1로 이용하므로 정답은 2이다.
- 2번: (-1, 0)에 충전소 하나를 설치하면 두 집까지의 거리는 1, 2이고 각각의 허용 거리를 만족한다. 따라서 정답은 3이다. 충전소 두 개를 써서 거리 합 2를 만들 수 있어도, 하나로 가능한 경우이므로 선택하지 않는다.
- 4번: 충전소 두 개로도 모든 집을 감당할 수 없어 -1이다.

## 복원 근거와 제한

| 항목 | 확인한 내용 |
|---|---|
| 설치 영역 | 두 풀이 모두 x, y를 -15부터 15까지 열거 |
| 집 위 설치 금지 | 집 좌표 집합에 포함된 후보를 제외 |
| 거리와 허용 조건 | 맨해튼 거리, `distance <= d` |
| 설치 우선순위 | 하나로 가능한 결과가 있으면 두 개를 검사하기 전에 반환 |
| 두 충전소의 비용 | 집마다 두 거리 중 작은 값을 합산 |
| 제공 입력 | 5개, N은 2~10, d는 1~11 |
| 시간 제한 | 응시자 기억에 따르면 50개 테스트케이스 합산 약 10초 |
| 미확인 | 공식 제목·서사, T·N·d의 전체 제한, 정확한 시간 및 언어별 차등 여부, 메모리 제한 |

제공 입력에서 관찰한 범위는 원문의 최대 제한을 뜻하지 않는다. 설치 좌표 범위와 연산 규칙은 코드에서 확인했지만, 원문·공식 출력이 없어 시험 문제와 완전히 같다고 확정할 수는 없다.
