# [B형 복원] 로봇 이동

> ⚠️ **원문이 아니라 시험 후 기억으로 복원한 연습판이다.** 알고리즘 구조(방향 상태 BFS +
> out_mask + 경유지 순열)는 검증했으나, 좌표계·교차로 규칙의 세부는 원문과 다를 수 있다.

**시간 제한**: Python 8초 · **메모리 제한**: 표준
**언어**: `Main` 고정 + `User Code`(init / build / move) 구현

---

## 문제

크기 **N × N** 의 격자 도시가 있다. 처음에는 건물도 도로도 없다.

**건물**을 추가하면, 그 건물의 바깥을 **한 칸 두께로 둘러싸는 도로**가 함께 생긴다.
건물은 직사각형이며 다음 정보를 가진다.

| 인자 | 의미 |
|---|---|
| `mID` | 건물 ID (중복 없음) |
| `mX, mY` | 건물 좌상단 좌표 (내부 기준) |
| `mW, mH` | 건물 너비 / 높이 |
| `mDoorX, mDoorY` | **건물 내부 기준** 출입구 상대 좌표 |

건물 내부 영역은 `x = mX … mX+mW-1`, `y = mY … mY+mH-1` 이고,
그 바깥 한 칸(`x=mX-1`, `x=mX+mW`, `y=mY-1`, `y=mY+mH`)이 도로다.

```
      도로
   O O O O O O
   O # # # # O
   O # # D # O      # : 건물 내부
   O # # # # O      O : 도로
   O O O O O O      D : 출입구(내부 가장자리)
      도로
```

- 건물끼리는 **겹치거나 붙을 수 없다.** 그러나 **바깥 도로는 서로 겹칠 수 있다.**
- 두 건물의 도로가 여러 칸을 공유할 수도 있다.

### 도로 이동 규칙 (시계방향)

로봇은 건물 주위 도로를 **그 건물 기준 시계방향으로만** 이동한다.

```
       → → → → →
     ┌───────────┐
     ↑           ↓
     ↑   건물    ↓        윗변 : →   오른변 : ↓
     ↑           ↓        아랫변 : ←  왼변 : ↑
     └───────────┘
       ← ← ← ← ←
```

도로 한 칸 이동 비용은 **1**. 일반 도로 중간에서는 방향을 바꿀 수 없다.

### 교차로

- 모든 건물 도로 사각형의 **네 꼭짓점은 교차로**다.
- 한 교차로에 여러 건물의 도로가 함께 있을 수 있다.
- 교차로에서는 **직진 / 좌회전 / 우회전 / U턴**이 가능하다.
  단, 그 방향에 실제 도로가 있고, 그 도로가 **어떤 건물의 시계방향 도로**여야 한다.
- 즉 교차로에 도착해야만 다른 건물의 도로로 갈아탈 수 있다.

### 출입구

- 출입구는 건물 내부 가장자리 칸이며, 바깥 도로와 정확히 한 칸 인접한다.
- **출입구를 드나들 때는 항상 "우회전"만 가능하다.** 즉 로봇 진행 방향 기준
  **오른쪽 한 칸**에 Door가 있을 때만 그 Door로 들어갈 수 있다.
- `도로 → Door` 비용 1, `Door → 도로` 비용 1. 건물 내부에서는 이동하지 않는다.

## API

### `init(N)`
크기 N × N 의 빈 도시를 만든다.

### `build(mID, mX, mY, mW, mH, mDoorX, mDoorY)`
건물 하나를 추가한다. 호출 횟수 최대 약 **1000**.

### `move(mStart, mEnd, M, mID)`
`mStart` 건물 출입구에서 출발해 `mEnd` 건물 출입구까지 이동한다.
`mID[0:M]` 의 **모든 경유 건물 출입구를 반드시 방문**해야 한다(방문 순서 자유, **M ≤ 5**).
모든 경유지 방문 후 목적지까지의 **최소 이동 거리**를 반환한다.
(이동 불가능한 경우는 입력으로 주어지지 않는다.)

---

## 입출력 형식 (Main)

첫 줄에 `T`(테스트케이스 수)와 `MARK`(배점). 각 테스트케이스는 명령 수 `Q` 와
`Q`개의 명령으로 구성된다.

| 명령 | 형식 |
|---|---|
| INIT  | `100 N` |
| BUILD | `200 mID mX mY mW mH mDoorX mDoorY` |
| MOVE  | `300 mStart mEnd M (mID×M) expected` |

`move`의 반환값이 `expected`와 모두 일치하면 그 테스트케이스는 `MARK`점, 아니면 0점.

---

## 제약 조건

- 2 ≤ N ≤ 수백
- 건물 수 ≤ 약 1000, 건물끼리 겹치거나 붙지 않음
- 경유지 M ≤ 5 (순열 5! = 120 이내)
- Door는 네 변 중 하나의 가장자리 칸

---

## 풀이 핵심

1. **상태에 방향을 넣는다** — `visited[y][x][dir]`. 같은 칸도 진행 방향이 다르면 다른 상태.
2. **도로를 `out_mask[y][x]` 비트로** — 그 칸에서 시계방향으로 나갈 수 있는 방향 집합.
   반대 방향 도로가 겹쳐도 두 비트가 함께 켜지므로 자연스럽게 처리된다.
   - 일반 도로: **현재 방향 비트만** 따라 진행
   - 교차로(`cross[y][x]`): `out_mask`에 켜진 **모든 방향**으로 분기
3. **Door 진입**: 진행 방향의 오른쪽(`(dir+1)%4`) 한 칸이 목표 Door면 +1로 진입.
4. **경유지**: 관련 건물들 간 Door→Door 최단거리를 BFS로 구한 뒤,
   경유지 순열(≤120)을 돌려 최소 합을 찾는다. (방향 그래프라 `dist[A][B] ≠ dist[B][A]`)
