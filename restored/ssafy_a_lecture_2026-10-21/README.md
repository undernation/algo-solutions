# SSAFY A형 강의자료 등록 (2026-10-21)

| 내부 번호 | 문제 | 예제 | 추가 제공 입력 |
|---|---|---:|---:|
| [SWEA 99994](https://undernation.github.io/algo-solutions/#p/SWEA/99994) | 면접 최소 점수 | 3개 | 28개 |
| [SWEA 99995](https://undernation.github.io/algo-solutions/#p/SWEA/99995) | 산악 구조 로봇 | 2개 | 3개 |

공식 SWEA 번호가 아닌 아카이브 내부 번호다. 날짜는 시험일이 아니라 등록일이다.
설명 MD와 입력 원본을 수정 없이 보존했다. 풀이 코드와 학습·제출 이력은 추가하지 않았다.

최소 점수 입력의 첫 줄은 30이지만 실제 입력은 31개다. 등록본은 모든 유효 입력을 포함하고 T를 각 묶음의 개수에 맞췄다.
산악 구조 로봇 MD에는 T=5 중 앞의 두 케이스만 있어, 공개 예제 입력의 T를 2로 바로잡았다.
원본 MD의 예제 출력과 대조했고, 출력이 없는 나머지 입력은 독립 구현과 제공 코드로 교차 검증했다.
추가 입력은 제공 파일에서 온 연습 케이스이며 공식 히든 테스트가 아니다.
최소 점수는 원본에 실행 제한이 없어 아카이브 기본 제한을 사용한다.

원본의 위치·해시는 [source_manifest.json](source_manifest.json), 검증 범위는 [verification.json](verification.json)에 기록했다.
