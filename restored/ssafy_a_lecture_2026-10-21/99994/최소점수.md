# 1. 면접 최소 점수

## 문제 설명

철수는 `N`개의 문제가 순차적으로 주어지는 면접에서 정확히 `M`개의 문제를 맞혔다. 어떤 문제를 맞혔는지는 기억나지 않지만, 정확히 `M`개를 맞혔다는 사실은 확실하다.

이 면접에서는 연속으로 문제를 맞힐 경우 점수를 더 많이 주는 **카운터 시스템**이 적용된다. 점수 계산 방식은 다음과 같다.

1. 카운터의 초기값은 `0`이다.
2. 문제를 틀릴 경우 카운터는 `0`으로 초기화된다.
3. 문제를 맞힐 경우 **1점**을 획득한 후 카운터가 `1` 증가한다.
4. 카운터가 주어진 값 `K`에 도달하면, 카운터는 `0`으로 초기화되고 **현재까지 획득한 총점이 2배**가 된다.

철수가 `M`개의 문제를 맞힐 수 있는 모든 경우 중 **최소 총점**을 구하라.

## 예시 설명

첫 번째 테스트 케이스에서 6번 문제를 틀리고 나머지 문제를 모두 맞히면 최소 점수인 **10점**을 얻는다.

문제가 진행되는 순서대로 총점은 `1 → 2 → 6 → 7 → 8 → 8 → 9 → 10`으로 변한다. 3번 문제를 맞혔을 때 1점을 획득해 총점이 3점이 된 뒤, 카운터가 `K=3`에 도달해 총점이 2배인 6점이 된다.

| 문제 번호 | 정답 여부 | 획득 점수 | 카운터 | 총점 | 비고 |
|---:|:---:|---:|:---:|:---:|---|
| 1 | O | 1 | 1 | 1 | |
| 2 | O | 1 | 2 | 2 | |
| 3 | O | 1 | 3 → 0 | 3 → 6 | 카운터 `K`에 도달, 초기화 |
| 4 | O | 1 | 1 | 7 | |
| 5 | O | 1 | 2 | 8 | |
| 6 | X | 0 | 0 | 8 | 오답으로 카운터 초기화 |
| 7 | O | 1 | 1 | 9 | |
| 8 | O | 1 | 2 | 10 | |

## 제약 사항

- `3 ≤ N ≤ 500`
- `1 ≤ M ≤ N`
- `2 ≤ K ≤ N`
- 풀이가 불가능한 경우는 주어지지 않는다.
- 정답은 32비트 `int` 범위를 넘지 않는다.

## 입력

첫 줄에 테스트 케이스의 수 `T`가 주어진다.

이후 각 테스트 케이스마다 한 줄에 `N M K`가 공백으로 구분되어 주어진다.

### 입력 예시

```text
3
8 7 3
3 3 3
5 2 3
```

## 출력

각 테스트 케이스마다 `#x`와 공백 한 칸을 출력한 뒤 최소 총점을 출력한다. `x`는 1부터 시작하는 테스트 케이스 번호이다.

### 출력 예시

```text
#1 10
#2 6
#3 2
```
