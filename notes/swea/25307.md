쉽다. r, c 를 그냥 dfs 변수로 넣으면 된다. 
만약 0 이나 1 인 숫자면, 값을 해당 범위 r, c, size 활용 에 넣는다. 
그리고 idx 는 += 1 해준다 이게 핵심이다. 
그리고 인코딩 코드처럼 아래 4방향에 대한 dfs 를 진행한다. 
앞 뒤로 idx += 1 씩 해줘야 괄호 처리가 제대로 된다. 
재귀로 들어가서 숫자면 그냥 리턴하고, board 값 초기화 숫자 아니면 또 한번 들어가서 idx + 1 된 상태에서 4단계 진행. 
가령 “(010(1001))” 라 해보자, 
첫번째 -> ( 라서 idx + 1 -> 1 현시점에서 dfs 4개 진행. 
첫번째 dfs -> 숫자라서 해당 범위 초기화 -> 2 
다음거 -> 숫자라서 해당범위 초기화... -> 4 까지. 이후 또 괄호 나와서 첫번째 조건에 안걸림 idx += 1 
이후 또 dfs 4 개 나오기. 
동일하게 숫자면 초기화. 아래 코드 그냥 외울것.
```python
def dfs(r, c, size, s): 
    global idx 
 
    if s[idx] == "0" or s[idx] == "1": 
        value = int(s[idx]) 
        idx += 1 
 
        for i in range(r, r + size): 
            for j in range(c, c + size): 
                board[i][j] = value 
 
        return 
 
    idx += 1 
    half = size // 2 
 
    dfs(r, c, half, s) 
    dfs(r, c + half, half, s) 
    dfs(r + half, c, half, s) 
    dfs(r + half, c + half, half, s) 
 
    idx += 1
```
