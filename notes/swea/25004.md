## SWEA 25004 경유지운송

#### 2026-08-24 (틀림)
못푼 이유
Widest Path에서 min(현재 병목, 간선 제한)은 떠올렸으나,
new_weight > dist[nxt]일 때만 갱신해야 한다는 relaxation을 적용하지 못함.

→ 개선되지 않은 경로도 계속 heap에 삽입함.

경유지는 도달 가능 여부만 확인하고 dist[eCity]만 반환함.
→ 양방향 / 순서 자유 / 재방문 가능이므로

min(dist[eCity], dist[모든 경유지])가 정답.

아래는 정석 풀이 코드
출발점 기준 widest dijkstra 한번
```python
def widest(start):
    dist = [-1] * g_N
    dist[start] = INF

    hq = [(-INF, start)]

    while hq:
        cur_weight, cur = heapq.heappop(hq)
        cur_weight = -cur_weight

        if cur_weight < dist[cur]:
            continue

        for nxt in graph[cur]:
            edge_weight = costs[cur][nxt]

            new_weight = min(cur_weight, edge_weight)

            if new_weight > dist[nxt]:
                dist[nxt] = new_weight
                heapq.heappush(hq, (-new_weight, nxt))

    return dist
```
돌아올수 있기 때문에 '필수 도시' 중 최솟값 산출
```python
def calculate(sCity, eCity, M, mStopover):
    dist = widest(sCity)

    answer = dist[eCity]

    if answer == -1:
        return -1

    for stop in mStopover:
        if dist[stop] == -1:
            return -1

        answer = min(answer, dist[stop])

    return answer
```
