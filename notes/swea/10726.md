## SWEA 10726 이진수 표현 D3

#### 2026-08-14 (품)
풀었으나, 비트 마스킹으로 푸는게 더 깔끔함

```python
import sys
sys.stdin = open("input.txt", "r")

T = int(input())

for test_case in range(1, T + 1):
    N, M = map(int, input().split())

    mask = (1 << N) - 1

    if M & mask == mask:
        answer = "ON"
    else:
        answer = "OFF"

    print(f"#{test_case} {answer}")
```
