왜 100의 단위로 공간분할을하는걸까?
-> 어차피 limit은 1000단위기 때문에
10으로 나눈 100단위로 하면 딱 정수로다가 거리 잴수있다.
그상태에서 100단위로 나누고, 여기서 중요한
section_cnt 를 쓴다 
section_cnt 란 섹션이 몇개인지를 정하는거다
section_cnt = (N + 99) // 100 -> 올림 나눗셈을 사용한다.
가령 N이 490 이면 5, (마지막 하나는 90 길이가 된다)
이런식으로 하면 한변이 몇 N인지 알수있다.
이제 그상태에서 list set 으로 공간분할 하면 끝.
