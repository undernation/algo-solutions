위상정렬, indegree 로 푸는 방법을 몰랐음

생각보다 쉽다. 일단은
indegree[x] 를 정의한다
이는 x하기전에 먼저 끝내야할 작업의 갯수를 의미한다.

아래 코드를 통해 선행작업이 없는 간선부터 시작이 가능하다.
그리고 그 간선을 진행하다가  디큐에서 현재 노드를 추가하면 끝난다.
아래 정답 코드
```python
import sys
from collections import deque
sys.stdin = open('sample_input.txt', 'r')

T = 10

for test_case in range(1, T + 1):
    V, E = map(int, input().split())
    data = list(map(int, input().split()))

    graph = [[] for _ in range(V + 1)]
    # 특정 간선 하기 전에 먼저 끝내야할 작업의 갯수
    indegree = [0] * (V + 1)

    for i in range(0, E * 2, 2):
        a = data[i]
        b = data[i + 1]

        graph[a].append(b)
        indegree[b] += 1
    q = deque()

    for i in range(1, V + 1):
        if indegree[i] == 0:
            q.append(i)

    answer = []


    while q:
        cur = q.popleft()
        answer.append(cur)

        for nxt in graph[cur]:
            indegree[nxt] -= 1

            if indegree[nxt] == 0:
                q.append(nxt)

    print(f"#{test_case}", *answer)

```
