init 조건 때문에 틀렸다.

처음에 쓴 조건은
```python
if is_present(node_a) and is_present(node_b):
```
서로 대표 노드인지 확인하는 것.
대표 노드면 대규모 그래프에서 간선 추가 해주고 간선 업데이트 함.

근데 여기서 문제가 하나 있는데,
이러면 소규모 그래프에서는 간선이 연결 안된걸로 된다는거다.
왜냐면 else 조건이 서로 같은 그룹을 처리하는 조건이기 때문.

따라서 조건은 서로 같은 그룹인지, (같은 그룹이면 소규모 처리, 다른 그룹이면 대규모 처리만 해주면됨)
아닌지만 따지는 코드로 진행하면 된다.
문제가 너무 안풀릴때는 조건 분기를 따져볼것...

```python
        if group_a != group_b:
```
