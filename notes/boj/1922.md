## BOJ 1922 네트워크 연결

#### 2026-10-27 (시간초과)
hq 를 사용하는 프림 알고리즘을 쓰는 법을  몰랐따...
그냥 dfs 사용하면 간선 탐색을 멈추게 되는 문제가 발생한다..

아래는 정답 코드

```python
from collections import defaultdict, deque
import heapq

N = int(input())
M = int(input())

cost_dict = dict()

graph = defaultdict(list)

for m in range(M):
    a, b, c = map(int, input().split())

    graph[a].append((c, b))
    graph[b].append((c, a))

    INF = 10 ** 18
    visited = [False] * (N + 1)
    visited[0] = True

    hq = [(0, 1)]

    answer = 0
    cnt = 0

while hq:
    cost, cur = heapq.heappop(hq)

    if visited[cur]:
        continue

    visited[cur] = True
    answer += cost
    cnt += 1

    for nxt_cost, nxt in graph[cur]:
        if not visited[nxt]:
            heapq.heappush(hq, (nxt_cost, nxt))

    if cnt == N:
        break

print(answer)


```
