맞아 ㅋㅋ. 정확히 그게 Union-Find로 이 문제를 풀 때 가장 까다로운 부분이야.

parent는 자식 → 부모 방향으로만 연결되어 있으니까, 특정 부모에서 모든 자식을 찾아 내려갈 수는 없지.

그런데 해결 방법은 의외로 간단해.

모든 셀을 순회하면서 find() 결과가 같은 셀을 찾으면 돼.

1. UNMERGE의 핵심 아이디어

예를 들어 다음과 같이 병합되어 있다고 해보자.

       (1,1) = "A"
       /       \
    (1,2)     (1,3)
                 |
               (2,3)

여기서 UNMERGE 1 3 명령이 들어오면?

먼저 (1,3)의 대표를 찾으면 돼.

root = find((1, 3))  # (1, 1)

그다음 전체 셀을 순회하면서 같은 대표를 가진 셀들을 찾는 거야.

members = []

for pos in parent:
    if find(pos) == root:
        members.append(pos)

이렇게 하면 다음 결과를 얻겠지.

members = [
    (1, 1),
    (1, 2),
    (1, 3),
    (2, 3)
]

이제 이 셀들을 모두 분리하면 돼.

2. UNMERGE 전체 코드

네 코드에 그대로 추가할 수 있는 형태야.

elif command[0] == "UNMERGE":
    r = int(command[1])
    c = int(command[2])

    target = (r, c)

    # 1. 현재 그룹의 대표 찾기
    root = find(target)

    # 2. 병합된 그룹의 값 저장
    saved_value = value[root]

    # 3. 같은 그룹에 속한 모든 셀 찾기

    for pos in parent:
        if find(pos) == root:
            members.append(pos)

    # 4. 모든 셀의 병합 해제 및 값 초기화
    for pos in members:
        parent[pos] = pos
        value[pos] = None

    # 5. 지정한 셀에만 기존 값 복원

여기서 중요한 부분이 두 개 있어.

⭐ ① 반드시 members를 먼저 찾아야 해

다음처럼 하면 문제가 생길 수 있어.

# 잘못된 방식
for pos in parent:
    if find(pos) == root:
        parent[pos] = pos

왜냐하면 parent를 순회하는 도중에 부모 관계를 변경하면, 아직 확인하지 않은 셀의 find() 결과까지 바뀔 수 있기 때문이야.

따라서 반드시 다음 순서를 지켜야 해.

# 이후 부모 관계 초기화
for pos in members:
    parent[pos] = pos

3. 그런데 모든 셀을 순회하면 비효율적이지 않나?

좋은 의문이야.

일반적으로 Union-Find에서 전체 노드를 매번 순회하는 건 비효율적인 방법이 맞아.

그런데 이 문제의 조건을 생각해 보자.

셀 개수: 50 × 50 = 2,500개
명령어 개수: 최대 1,000개

극단적으로 모든 명령어가 UNMERGE라고 해도 확인할 셀은 최대 250만 개야.

경로 압축이 적용된 find()를 사용하면 이 정도는 Python으로 충분히 처리할 수 있어.

따라서 이 문제에서는 child 딕셔너리를 별도로 관리할 이유가 크지 않아.

4. 여기서 배우면 좋은 알고리즘 개념

Union-Find는 기본적으로 그룹을 합치는 데 특화된 자료구조이지, 그룹을 분리하는 데 특화된 자료구조가 아니야.

연산	Union-Find
같은 그룹인지 확인	매우 효율적
두 그룹 병합	매우 효율적
특정 그룹의 모든 구성원 조회	별도 작업 필요
그룹 분리	직접 구현 필요

실제로 그룹 분리 연산이 빈번하고 노드가 수백만 개라면 다른 자료구조까지 고민해야 해.

하지만 프로그래머스 표 병합에서는 전체 순회가 가장 구현하기 쉽고 실용적인 방법 중 하나야.

참고로 네 코드 맨 위의 from collection import defaultdict는 from collections import defaultdict로 고쳐야 실행돼.

5. 수정한 전체 코드

네가 작성한 구조를 최대한 유지하면서 수정하면 다음과 같아.

parent = {}
value = {}

def find(pos):
    while parent[pos] != pos:
        parent[pos] = parent[parent[pos]]
        pos = parent[pos]

    return pos


def solution(commands):
    global parent, value

    parent = {}
    value = {}
    answer = []

    for i in range(1, 51):
        for j in range(1, 51):
            parent[(i, j)] = (i, j)
            value[(i, j)] = None

    for command in commands:
        command = command.split()

        if command[0] == "UPDATE":

            if len(command) == 4:
                r = int(command[1])
                c = int(command[2])
                cur_value = command[3]

                root = find((r, c))
                value[root] = cur_value

            elif len(command) == 3:
                value1 = command[1]
                value2 = command[2]

                for pos in parent:
                    if parent[pos] != pos:
                        continue

                    if value[pos] == value1:
                        value[pos] = value2

        elif command[0] == "MERGE":
            r1 = int(command[1])
            c1 = int(command[2])
            r2 = int(command[3])
            c2 = int(command[4])

            root1 = find((r1, c1))
            root2 = find((r2, c2))

            # 이미 같은 그룹
            if root1 == root2:
                continue

            value1 = value[root1]
            value2 = value[root2]

            merged_value = value1 if value1 is not None else value2

            parent[root2] = root1

            value[root1] = merged_value
            value[root2] = None

        elif command[0] == "UNMERGE":
            r = int(command[1])
            c = int(command[2])

            target = (r, c)
            root = find(target)

            saved_value = value[root]

            members = []

            for pos in parent:
                if find(pos) == root:
                    members.append(pos)

            for pos in members:
                parent[pos] = pos
                value[pos] = None

            value[target] = saved_value

        else:
            r = int(command[1])
            c = int(command[2])

            root = find((r, c))

            if value[root] is None:
                answer.append("EMPTY")
            else:
                answer.append(value[root])

    return answer

parent[pos]	바로 위 부모
find(pos)	최종 대표 노드
parent[root2] = root1	두 그룹 병합
value[find(pos)]	해당 셀이 속한 그룹의 값

그리고 네 find()는 이미 경로 압축을 구현했어.

def find(pos):
    while parent[pos] != pos:
        parent[pos] = parent[parent[pos]]
        pos = parent[pos]

    return pos

이 코드도 제대로 작성했어.

🎯 결론

지금은 알고리즘 설계가 잘못된 게 아니라, 구현상 두 부분을 놓친 거야.

특히 PRINT에서 parent[pos]를 사용한 건 꽤 중요한 실수인데, 앞으로 Union-Find 문제를 풀 때는 다음 원칙을 기억하면 돼.

그룹의 대표가 필요하다면 항상 find()를 호출하자.

이 두 부분만 수정하면 현재 풀이로 정답을 받을 수 있어.
