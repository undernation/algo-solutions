## 반례와 원인

`solution(2, 4, 3)`의 정답은 `1`(2 × 2)이고 원본 반환값은 `-1`이다.
`range(x, y - n + 1)`은 덧셈 기준으로 반복 구간을 잘라 곱셈 전이를 놓친다.
원본은 `programmers/154538_숫자변환하기.py`에 그대로 보존했다.

## 최소 수정본 (AI 도움, 자력 재풀이 전)

`range(x, y + 1)`로 반복 범위 한 줄만 수정했다.

```python
def solution(x, y, n):
    answer = 0
    INF = 10 ** 18
    dp = [INF] * (y + 1)

    dp[x] = 0

    for i in range(x, y + 1):

        if dp[i] == INF:
            continue

        cur_cnt = dp[i]

        nxt_num = i + n

        if nxt_num <= y:
            dp[nxt_num] = min(dp[nxt_num], cur_cnt + 1)

        nxt_num = i * 2
        if nxt_num <= y:
            dp[nxt_num] = min(dp[nxt_num], cur_cnt + 1)

        nxt_num = i * 3
        if nxt_num <= y:
            dp[nxt_num] = min(dp[nxt_num], cur_cnt + 1)

    if dp[y] == INF:
        return -1
    else:
        return dp[y]
```
