## CT 2026 두 수의 합

#### 2026-10-30 (틀림)
해시맵으로 on 으로 탐색하는 방법을 바로 떠올리지 못함.
풀이법을 최적화 하는데서 실수가 있었음.

쉬움
```python
from collections import defaultdict

N, K = map(int, input().split())
arr = list(map(int, input().split()))

temp_dict = dict()

answer = 0

for num in arr:

    diff = K - num

    if diff in temp_dict:
        answer += temp_dict[diff]

    if num in temp_dict:
        temp_dict[num] += 1
    else:
        temp_dict[num] = 1

```
