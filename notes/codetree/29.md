## CT 29 가능한 수열 중 최솟값 구하기

#### 2026-10-02 (틀림)
수열의 검사를 구현하지 못했음.
검사는 아래와 같다. 이해하면 쉽다.

```python
def check_ok(num_list):
    length = len(num_list)
    for size in range(1, length // 2 + 1):
        right = num_list[-size:]
        left = num_list[-2 * size:-size]
        if left == right:
            return False

    return True
```
